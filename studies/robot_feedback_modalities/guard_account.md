# Working bounded empty-closure handoff

All four predefined fixed fixtures passed. Both report-only cases reproduced the original Astra action/state prefixes exactly. The armed negative case reproduced the same prefix through step 120, then cancelled the 45-step lift and returned a fresh observation on stable empty-sized closure. The positive retry ran through step 335 in both conditions without an armed interruption and retained private frame-grasp contact. These outcomes verify command behavior and a necessary-condition warning; they do not establish improved ToolHang success or faster task completion.

Every run retains its configuration, original policy-selected command source, source hashes, public camera/sensor snapshots, executed actions/states, monitor readings, execution reports and native outcome. Independent replay also verifies the saved sensor readings and outcome. The negative stopped fixture saves 2.25 seconds of simulated empty transport; this is avoided motion in a verification case, not an end-to-end speed claim. No new Astra calls were made.

The command field is `abort_if_empty_close`. Astra decides whether an occupied grasp is expected and whether to arm it, then selects any recovery after handoff. The executor uses public finger opening/velocity and a shared empty-gripper calibration. It never supplies an object identity, chooses a new target, opens the fingers automatically or declares acquisition. Compensated load and progress signals remain advisory so the next comparison can isolate this particular stop/handoff boundary.

The next necessary policy test will freeze two new matched starts and timed/guarded conditions, with identical sensor/calculation access, waypoint capability, controller, budgets and medium-effort Astra. The strong timed baseline can use separate close/observe commands. Full native success and every scheduled outcome remain required, along with calls, time and cost; two states cannot establish reliability or generality. This prototype is a runnable milestone in the broader FYP.
