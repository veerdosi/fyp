# Smallest bounded mechanism: model-armed empty closure handoff

Recorded after the complete sensor screen, before implementation or verification. CoTracker is not required. This is a revised H3 / temporal-continuation question: does handing control back when a declared grasp expectation is visibly contradicted prevent empty transport or reduce unnecessary robot/model work? Empty finger opening is a necessary-condition warning for these objects, not a complete acquisition or seating test.

Extend a waypoint with optional `abort_if_empty_close: boolean`. Astra chooses whether to arm it on a closing or carrying waypoint. It requires gripper +1. The same shared calibrated sensor monitor operates in both comparison conditions. Timed control reports flags at normal handoff; guarded control cancels the current and remaining waypoints and returns a fresh public observation on the first armed stable empty-sized closure. Keep the original controller, pose/action/workspace bounds and permitted temporary calculation tools. A flag never chooses a grasp, opens the fingers, moves to a recovery pose or declares task completion.

Use the original frozen empty-sized rule: sum of absolute finger positions <= maximum empty-closed calibration opening + 2 mm, finger velocity norm <= 0.001 m/s for three readings, minimum ten steps per waypoint. The threshold is shared across starts and conditions and comes only from the two empty-gripper training calibrations. Log force/progress/empty signals for all waypoints, but only the armed empty-sized signal can stop this prototype. Do not tune thresholds on task outcomes. Brief zero-delta holding during observation is allowed only if explicitly logged; no corrective movement is hidden.
